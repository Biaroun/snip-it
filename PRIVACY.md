# Privacy Policy — Snip It

**Last updated: July 31, 2026**

Snip It is a Chrome extension that lets you save selected text from web
pages as notes.

## Data collection

Snip It does **not** collect, transmit, or share any personal data. It has
no backend server and makes no network requests.

All notes and settings you create are stored locally on your device using
Chrome's built-in `storage` API (`chrome.storage.local` for notes,
`chrome.storage.sync` for preferences, which Chrome may sync across your
own signed-in devices — this is handled entirely by Chrome, not by us).

## Permissions used

| Permission    | Why it's needed                                              |
| ------------- | -------------------------------------------------------------- |
| `contextMenus` | To add the "Save as note" option to the right-click menu.     |
| `storage`      | To save your notes and preferences locally on your device.    |
| `downloads`    | To let you export your notes as a Markdown file when you choose to. |

## Third parties

Snip It does not use analytics, trackers, or any third-party services.
